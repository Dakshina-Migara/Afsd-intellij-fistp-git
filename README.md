# Core Java Exercises

> This repository tracks my journey in learning Java. It includes practical examples and exercises covering fundamental programming concepts, object-oriented programming (OOP), multi-dimensional arrays, and encapsulation methodologies.

## 📌 About The Project

This project contains various hands-on activities, from basic algorithms to more advanced OOP concepts.

**Key Topics Covered:**
*   **Java Basics**: Variables, control flow (`if`/`else`), loops (`for`, `while`), and methods.
*   **Object-Oriented Programming (OOP)**:
    *   Classes and Objects
    *   Inheritance and Encapsulation
    *   Polymorphism (Compile-time & Run-time)
    *   Abstraction and Interfaces
*   **Data Structures**: Single and Multi-dimensional Arrays.
*   **Real-world Modeling Activities**: Simple Bank System, Vehicle Hierarchy, and Employee Management examples.
